# DocScan Iran — اسکنر هوشمند مدارک دانشگاهی

- **GitHub Pages:** بیلد استاتیک آماده در `docs/` است. Settings → Pages → Branch `main` و پوشه‌ی `/docs`.
  بازسازی: `npm install --legacy-peer-deps && npm run build:pages`
- **هاست Node.js:** `npm install --legacy-peer-deps && npm run build:node && npm start`
